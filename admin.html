⬢ Адмін-панель

Зміни зберігаються прямо у твій репозиторій на GitHub. Редагувати може лише той, у кого є токен із правом запису в цей репозиторій.

Як отримати токен?
  1. Відкрий GitHub → Fine-grained token.
  2. Repository access → Only select repositories → обери репозиторій сайту.
  3. Permissions → Repository → Contents: Read and write.
  4. Згенеруй токен і встав його сюди. Нікому його не показуй.
